# Windows 多屏 DPI 定位验证

此清单需要在 Windows 实机执行；纯几何单元测试不替代 Windows 的
`WM_DPICHANGED`、任务栏和显示器热插拔验证。

## 显示配置

每组至少测试一次「Earth 上次在 A 屏、这次从 B 屏打开」以及反方向。

| A 屏 | B 屏 | 排列 |
| --- | --- | --- |
| 150% | 100% | B 在 A 右侧 |
| 200% | 125% | B 在 A 左侧，桌面 X 为负 |
| 150% | 100% | B 在 A 上方，桌面 Y 为负 |
| 100% 横屏 | 150% 竖屏 | 高度不齐、竖屏在左侧 |

## 每组操作

1. 将 Earth 在 A 屏打开后隐藏，鼠标移到 B 屏，分别在四角和中央用快捷键打开。
   「光标」模式应出现在光标附近；靠边时应留在 B 屏工作区内。
2. 切换「屏幕中心」，重复跨屏打开。位置应相对鼠标所在屏居中，
   不应跳回上次 Earth 所在屏。
3. 将目标应用放在 B 屏，鼠标留在 A 屏，用快捷键打开「窗口中心」模式。
   弹窗应在目标应用所在屏，尺寸足够时应位于其窗口中心。
4. 启用两屏任务栏，在 B 屏托盘点击 Earth。弹窗应在对应托盘附近，
   保留任务栏工作区边界。隐藏后移动鼠标到 A 屏，再从托盘菜单打开：
   已缓存的托盘锚点应保持在原屏的同一物理位置。
5. 在 B 屏展开及收起预览工作台，再隐藏并从 A 屏打开。
   弹窗应恢复紧凑尺寸，不出现累积偏移。
6. 连续跨屏打开至少十次，检查弹窗的逻辑尺寸保持一致、文字按当前屏缩放、
   边缘不被屏幕或任务栏裁掉。
7. 如启用了 egui 界面缩放，放大一次后重复步骤 1–4，
   检查边界计算包含界面缩放后的实际尺寸。

## 额外检查

- 任务栏设为顶部、左侧、右侧或自动隐藏时，弹窗仍在可用工作区内。
- Earth 隐藏期间改变某屏缩放或拔掉外接屏，再次打开应落在现存显示器内。
- 显示器可用空间小于弹窗时，应固定在该屏左上方内边距处，不产生 NaN、
  崩溃或跨屏漂移；空间不足时无法保证完整显示。
- 记录每组 Windows 版本、屏幕分辨率、缩放、排列、打开模式和结果。

## 自动覆盖

`cargo test --offline platform::positioning::tests` 覆盖目标屏尺寸换算、
当前 viewport 单位转换、负坐标、托盘及窗口锚点、竖屏和极小工作区。
`cargo test --offline tray::tests` 覆盖托盘物理矩形与点击坐标的回退。
