# Earth 问题处理记录 · 2026-11-19

本报告记录 Earth 仓库中 #1–#53 的处理结果，分为 **41 项缺陷与维护修复**和 **12 项尚未实施的功能提案**。

## #10 合成历史基准

入口位于 [storage/history.rs](../src/storage/history.rs)，默认忽略，可独立执行：

```sh
cargo test history_5000_rows_2000_thumbnails_benchmark -- --ignored --nocapture
```

本轮测量使用 macOS 本地 **debug** 构建和临时数据库：5000 条记录，其中 3000 条为约 1 KiB 文本并附数据库富文本列，2000 条图片记录对应 2000 个实际 8×8 PNG 缩略图文件。查询各执行五轮，报告均值；不读写用户历史，测试结束清理临时数据。

| 测量项 | 本轮结果 | 测量含义 |
| --- | ---: | --- |
| 首屏 64 条读取 | 0.53 ms | 列表字段不包含 HTML / RTF。 |
| 首次完整后台快照及应用 | 133.99 ms | 全部 5000 条载入共享记录并应用初始快照。 |
| 无变更增量检查 | 10.42 ms | 扫描记录标记，不重新传输正文。 |
| 存储目录统计 | 5.97 ms | 统计该合成数据库及 2000 个媒体文件。 |
| 空查询 | 0.37 ms | 5000 个结果只共享记录引用。 |
| 精确查询 `needle` | 38.70 ms | 命中 3000 条文本。 |
| 模糊查询 `needle` | 120.50 ms | 命中 3000 条文本。 |
| 正则查询 `n[e]+dle` | 30.61 ms | 命中 3000 条文本。 |

基准逐条断言搜索结果与历史快照的 `Arc::ptr_eq` 相同，并验证列表未读取 HTML / RTF。普通回归另外覆盖：首次快照前删除记录、后续新增 / 修改 / 删除、未变化记录保持引用、单项读取保留富文本、首屏数量上限、统计按需与节流，以及同长度编辑使预览缓存更新。

这些数值用于本轮对比与后续复测，不能外推为真实图像解码、GPU 显存、完整启动耗时或 release 构建性能。计时不包含 `Storage::open_in_dir` 的权限检查、迁移和启动孤儿媒体检查。查询仍在主线程线性执行；本轮 debug 模糊查询约 120 ms，不能据此宣称大历史搜索已经没有停顿。

## 平台验收边界

- **#14 发布与安装：** 正式 macOS / Windows 签名、公证、原生安装门禁和升级回滚仍需合法凭据与对应系统。当前证据包括合成版本比较、拒绝不可信签名和安装描述编译，没有真实安装完成的证据。
- **#34 自动粘贴：** 目标身份确认和发键成功只表示系统调用路径成功，无法证明目标应用已处理文本；需要分别在 macOS 授权桌面会话和 Windows 普通 / 提权目标窗口验证。
- **#35 采集完整性：** macOS 轮询无法恢复两次采样之间已被覆盖的剪贴板值；有界队列控制内存并报告拥塞，不保证每个瞬时变化均保存。来源采样仍可能与实际复制应用不同。
- **#41 多屏定位：** 几何测试不是 Windows 显示系统测试。须按手动清单验证缩放改变、显示器热插拔、竖屏、负桌面坐标和托盘跨屏。
- **Windows 工具链：** 本机尝试 `cargo check --offline --locked --target x86_64-pc-windows-msvc` 时，因缺少 Windows Rust 标准库返回 `E0463`；同时缺少 MSVC / MinGW C 工具链与资源编译器。隔离检查覆盖了选定的 `windows-sys` 调用（剪贴板、单实例事件、WinHTTP 和 DPI 定位）；不能替代完整 Windows 构建、链接或运行。
- **本地存储与预览：** 历史及备份没有静态加密；敏感遮罩只控制显示。图片允许采集 / 备份的大小与受限预览大小不同，超出预览上限仍需在外部图片应用查看。
